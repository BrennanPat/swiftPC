# SwiftPC ⚡

**SwiftPC** is a modern, lightweight system performance and optimization utility for Windows. Designed with a sleek dark UI, it gives you real-time visibility into your hardware metrics and provides tools to clean up storage, manage startup programs, and boost system speed.

## ✨ Features

* **📊 Live System Overview**
  * Real-time monitoring for **CPU usage**, **RAM allocation**, **SSD storage space**, and **DNS latency**.
  * Dynamic overall health score rating your system's current performance state.

* **🧹 Junk Cleaner**
  * Scans both User Temp and Windows Temp directories to safely reclaim disk space.

* **🚀 Startup Manager**
  * View and toggle startup applications to improve Windows boot times.
  * Displays impact ratings (High/Low) and file paths for full control.

* **⚡ RAM Booster**
  * Displays reclaimable memory and standby cache to free up active RAM usage.

* **🌐 DNS Optimizer**
  * Measures current resolver path latency and server responses for web optimization.

* **📁 Storage & Registry Utilities**
  * Detailed drive breakdown and registry issue detection.
